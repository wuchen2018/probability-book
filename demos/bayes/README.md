# 贝叶斯检测实验

[打开在线实验](https://wuchen2018.github.io/probability-book/demos/bayes/)

配套《大白话概率论》第3.4节。讲解分成四步：先把10万人分成患者和健康人，分别做检测，只留下测出阳性的人，最后计算患病的概率。每一步单独展示当前需要观察的人数和计算。默认参数与书中相同：患病率0.1%，灵敏度99%，假阳性率1%。

看完讲解后，点“自己改一改患病率”，可以改变患病率，比较真阳性与假阳性人数；也可以展开“也改变检测方法”，调整灵敏度和假阳性率。讲解默认由读者点击“下一步”；自动播放可暂停、调整速度，第二步会留更长的时间看计算。

手机调参时，页面上方会保留真阳性人数、假阳性人数和患病概率，方便一边改参数、一边看结果。

页面不需要安装Python，也不依赖外部脚本。源码为同目录的HTML、CSS和JavaScript。开发时在仓库根目录运行 `python -m http.server 8000`，浏览器访问 `http://localhost:8000/demos/bayes/`。
