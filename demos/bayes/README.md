# 贝叶斯检测实验

[打开在线实验](https://wuchen2018.github.io/probability-book/demos/bayes/)

配套《大白话概率论》第3章「条件概率与贝叶斯公式」、第3.4节「贝叶斯公式」，纸书第77—88页。[阅读公开样章](../../samples/bayes-theorem.pdf)。样章PDF单独分页，页码与纸书不同。

打开页面就可以拖动滑块或输入患病比例，也可以设置患者测出阳性的比例、健康人被误判为阳性的比例。参数、人数、推导文字和最后的概率会即时更新。默认参数与书中相同：患病率0.1%，灵敏度99%，假阳性率1%。

页面按患病比例、检测比例、人数推导、最终概率分块。正文先解释10万人怎样分成100名患者和99,900名健康人，再分别说明99名真阳性、999名假阳性怎样算出，最后合并1,098名阳性并计算9.02%。每组的起始人数、检测比例、算式、阳性和阴性人数都有对应说明。检测设置和补充解释默认展开，读者可以自己收起。

需要逐步理解时，可以点“分四步看计算过程”。读者随时可以返回交互实验，切换时保留自己填写的参数。四步讲解也支持暂停和调速的自动播放。

调参时，设置区上方会保留两组阳性人数和患病概率，方便一边改参数、一边看结果；往下阅读完整推导时，摘要随设置区退出，不遮住计算内容。

页面不需要安装Python，也不依赖外部脚本。源码为同目录的HTML、CSS和JavaScript。开发时在仓库根目录运行 `python -m http.server 8000`，浏览器访问 `http://localhost:8000/demos/bayes/`。
