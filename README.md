## 这本书怎么讲

### 把公式中间省掉的过程讲出来

自学数学时，我经常遇到一种情况：公式看得懂，前后两行怎么接上的，却要自己想很久。所以写这本书时，我会多写一些文字，把中间的想法和步骤交代清楚。

比如讲条件概率，我先从一副牌里抽到红心 A 说起。加入“已知抽到的是红色牌”这个条件以后，可选的牌从 52 张缩到 26 张，概率也随之改变。读者先看清这个变化，再去理解条件概率公式。

讲贝叶斯公式时，我会先拿具体的人数来算一道检测题，让你看到为什么检测结果是阳性，也未必有很高的患病概率；算完以后，我们再看公式的每一部分分别对应什么。

### 把各种分布之间的联系串起来

同一个人投篮，投一次进不进、投十次进几个、等到第一次投进、等到第三次投进，对应的是伯努利分布、二项分布、几何分布和负二项分布。把问题放在一起看，你更容易分清这些分布各自在描述什么。

书里还会继续讲离散分布和连续分布怎样联系起来：几何分布和指数分布为什么都有无记忆性，泊松分布描述的事件次数和指数分布描述的等待时间是什么关系。学到后面，可以回过头，把这些分布之间的关系重新梳理一遍。

### 学完数学，接着看看它在 AI 里怎么用

我毕业后做了六年算法工作，写书时也把工作里经常用到的数学放了进来：

- 大模型为什么同一个问题每次回答不一样？从 Softmax、概率分布和温度参数讲起。
- 怎样用向量判断两段文字像不像？从内积、余弦相似度讲到大模型中的应用。
- 交叉熵和 KL 散度在比较什么？从信息熵继续往下讲。
- 怎样根据观测到的数据反推参数？从最大似然估计来理解。

书里设有“AI视野”和“Python实验室”。你既可以看到这些知识用在什么地方，也可以运行代码、改改参数，观察结果怎样变化。

### 把容易想错的问题拿出来，慢慢算清楚

三门问题里，主持人知道不知道车在哪，为什么会改变答案？辛普森悖论里，为什么每一组都更好，合在一起却更差？连续输了很多次，下一次是不是就更容易赢？

这些问题很适合检查我们对概率的理解。书里会把规则、条件和计算过程写出来，也会讨论赌徒谬误、赌徒输光、幂律分布等话题。生活中的例子包括抽牌、投篮、天气，也包括三国杀、麻将和狼人杀。

### 兼顾系统学习、练习和动手实验

书中从概率论基础讲到数理统计，也收录了 2024—2026 年考研数学一、数学三的部分概率论真题，以及算法岗面试概率题，并提供详细解答。

章首有思维导图二维码，章末有学习目标、核心考点、思考题和配套解答。学完以后，你可以对照检查哪些地方已经理解，哪些还需要回头看看。各小节的 Python 实验也可以用来模拟和验证刚学到的结论。

## 我一个文科生，为什么要写一本概率论教材？

我高中读文科，本科在武汉大学读金融，研究生转到数学院，毕业后做 AI 算法工作。一路上，很多东西都是靠自学的。

我喜欢概率论，也吃过自学教材时跳步太多的苦。我一直想写一本书，把自己对概率论的直观理解、知识点之间的联系，尽量完整地交给读者。写的时候，我会想象自己坐在学弟学妹旁边辅导：他读到这里会不会卡住？这个概念是不是还需要多举一个例子？上一句和下一句之间，是不是还少了一步解释？

我把这段经历写成了《我一个文科生，为什么要写一本概率论教材？》，聊了我怎样从文科走到金融、数学和算法，为什么想写这本书，以及我怎样对着手机口述、想象自己在上课，再把内容整理成文字。

你可以读[公众号原文](https://mp.weixin.qq.com/s/7EljXwIEG68a3aM9GUxmJQ)，也可以看我在[知乎推荐概率论教材的回答](https://www.zhihu.com/question/443593798/answer/2103099699775411468)里对写书经历的介绍。

## 适合哪些读者

- **正在自学概率论与数理统计**：想从具体例子和直觉出发，跟着推导理解公式。
- **以前学过，但知识点比较零散**：想重新理解不同分布的关系，以及一些反直觉结论为什么成立。
- **学习 AI，想补数学基础**：希望把条件概率、期望、相关性、信息熵、参数估计和模型中的用法联系起来。
- **准备期末考试或考研**：可以结合自己的考试大纲，先读基础内容和真题详解，再按兴趣阅读扩展部分。

前面的章节可以从高中数学基础读起；后面涉及连续型随机变量、多维分布等内容时，需要相应的求导、积分等微积分基础。
