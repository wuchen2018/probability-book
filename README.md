## 这本书是怎么讲的

我自学概率论的时候，最怕的就是教材跳步。公式明明每一行都看得懂，上一行怎么变成下一行的，却要自己琢磨很久，有时候琢磨半天也想不通，只好先背下来。所以写这本书时，我给自己定了一个要求：**用大白话讲，不跳步**。每写一段，我都会想，读者读到这里会不会卡住？如果会，那就多写几句。书因此厚了一些，但我宁愿多说一句，也不想让你卡在我省掉的那一步上。

“大白话”是讲法，内容还是大学阶段的概率论与数理统计，从随机事件、条件概率一直讲到参数估计和假设检验。只是在给出一个定义之前，我会先告诉你，它想解决什么问题，我们为什么需要它；公式推出来以后，再回头看看它符不符合你的直觉。我一直觉得，学概率论要**从直觉出发**。很多结论，直觉上想明白了，就用不着死记硬背。

我自己学概率论时还有一个很大的收获：**很多知识点其实是连在一起的**。就拿几种常见分布来说，很多教材是一个一个分开讲的，学完以后，脑子里常常只剩一堆名字和公式。但如果把它们放回同一个场景里，换着问问题，它们之间的关系就清楚了：

| | 一次一次地投篮 | 时间里随机打进来的电话 |
| --- | --- | --- |
| 数一数发生了几次 | 投 10 次，进了几个？<br>**二项分布** | 一小时里来了几个电话？<br>**泊松分布** |
| 等第一次 | 第一次投进，要投几次？<br>**几何分布** | 下一个电话要等多久？<br>**指数分布** |
| 等第三次 | 第三次投进，要投几次？<br>**负二项分布** | 第三个电话要等多久？<br>**伽马分布** |

同样是投篮，或者等电话，你问的是发生了几次、等第一次，还是等第三次，问题一变，分布也就跟着变了。第 6.7 节和第 7.6 节专门把这些分布串起来讲。不只是分布，前面学的期望、全概率公式，到了后面也会一次次用上。每到这种地方，我都会提醒你回头看一眼。

除了这些，书里还有一些我很喜欢的内容。不少读者是冲着 AI 来的，所以很多小节的末尾有“**AI视野**”，告诉你刚学的东西在大模型、搜索和推荐里用在哪里。书里也讨论了三门问题、辛普森悖论这些很容易让直觉出错的问题，例子里有三国杀、麻将和狼人杀。准备考试的话，第 20 章有 2024—2026 年考研数学一、数学三的部分**概率论真题详解**，还有一节是**大厂算法岗面试里的概率题**。每章开头有思维导图二维码，结尾有学习目标、核心考点和思考题；很多小节后面还有“**Python实验室**”，改一个参数，就能看到结果怎么变。

## 适合谁读

如果你正在自学概率论与数理统计，或者以前学过，总觉得有些地方没想通，这本书最适合你。准备期末或考研的话，标了“扩展”的小节可以先跳过，先读主干内容和第 20 章的真题；各校考纲不一样，以你自己的考试要求为准。如果你在学 AI，想把概率统计补扎实，可以多留意每节末尾的“AI视野”。

关于基础，你不需要等微积分和线性代数都学完再来读。前面几章用高中数学就够了。从连续型随机变量开始，会用到求导和定积分；讲多维随机变量时，会用到二重积分。书里的积分都是比较常见的计算，没有难题怪题。线性代数知道向量和矩阵的基本定义就行。Python 会一点基础语法就能跑实验，不写代码也不影响读正文。

如果你已经学得比较熟，只想补其中几块，可以直接翻目录，挑自己需要的那几节读。书里有例题、真题和思考题，想再多刷些题的话，可以另配一本习题集。

## 我为什么写这本书

我高中读文科，本科在武汉大学读金融，研究生转到数学与统计，毕业后做了约六年算法工作。读金融时我就喜欢上了概率论，因为很多经济模型都要用概率去解释。一路上很多东西是靠自学的，也正因为这样，我知道自学的人会在哪里卡住。工作以后，我发现 AI 底层用到的很多都是概率论，交叉熵、Softmax、贝叶斯公式、条件概率，到处都是，想写这本书的念头也就越来越强。

写的时候，我想象自己坐在学弟学妹旁边辅导，先对着手机把一节内容讲出来，再转成文字，一句一句地改。整个过程里哪些环节用了 AI、每一步花多少时间，我都写在了书的第一篇前言里。从动笔到定稿，前后花了七个多月。

更完整的经历，我写成了《我一个文科生，为什么要写一本概率论教材？》，可以读[公众号原文](https://mp.weixin.qq.com/s/7EljXwIEG68a3aM9GUxmJQ)，也可以看我在[知乎推荐概率论教材的回答](https://www.zhihu.com/question/443593798/answer/2103099699775411468)。
