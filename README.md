## 关于这本书

一本适合自学的概率论与数理统计教材，700多页。用大白话、生活中的例子和详细推导，把公式背后的道理讲清楚，也把各个知识点之间的联系串起来。

- **先建立直觉，再理解公式**：讲清概念的来由、推导过程和不同知识点之间的联系。
- **数学与AI相结合**：结合Softmax、余弦相似度、交叉熵、KL散度等内容，设有“AI视野”和“Python实验室”。
- **学习与练习相结合**：收录2024—2026年考研数学一、数学三的部分概率论真题，以及算法岗面试概率题的详细解答。
