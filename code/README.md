# 《大白话概率论》Python实验室

这里收录书中“Python实验室”的76份脚本，按原有章节目录保存，文件名保留原样。

## 使用方法

先安装 Python 3，再在本目录执行：

```bash
python -m pip install -r requirements.txt
```

按下面的章节目录找到脚本，在终端中运行。比如第一章的抽卡模拟：

```bash
python chapters/introduction_to_probability_theory/introduction/python_demo/gacha_simulator.py
```

有些脚本会在终端里请你输入参数，有些会打开图形窗口。你可以跟着书中的实验说明，改变参数，观察结果。

如果想下载全部代码，在[仓库主页](../)点击绿色的 **Code → Download ZIP**，解压后打开 `code` 文件夹。
